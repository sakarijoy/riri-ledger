# 日日记账

[打开日日记账](https://sakarijoy.github.io/riri-ledger/)

手机记账与月度资产工具。账单、照片和资产记录存储在使用中的浏览器，可通过「备份与恢复」迁移。

页面源码在 `dist/`，离线缓存和桌面图标资源在 `pwa/`。运行 `node build.mjs` 生成 `docs/` 里的 GitHub Pages 文件和独立离线版 `offline.html`。更新线上版时一并提交源码和生成文件。

## 两人合计的 GitHub 同步

1. 在双方都是成员的 GitHub 组织中创建专用的私有仓库，并添加 README。
2. 两人分别创建细粒度令牌，资源所有者选择该组织，只授权这个仓库的 **Contents 读写**。如果组织要求审批，先批准令牌。
3. 各自在平时记账的手机打开「备份与恢复 → GitHub 同步 → 连接设置」，填相同的 `组织名/仓库名`、对方的 GitHub 用户名和自己的令牌。

「两人合计」仅向通过 SZ2825 组织成员验证并能访问所配私有仓库的账号显示。每次重新打开应用需要联网验证。未验证时导航显示两个入口，直接打开 `#combined` 会显示账本概览。若 GitHub 限制令牌查询自己的组织身份，需要为令牌增加组织 **Members 只读**权限并完成组织审批。

应用把每人的月度收入和支出汇总写入各自的 JSON 文件。联网保存账单会自动同步，页面在前台时每分钟读取更新。可以点「立即同步」提前读取。账单明细、照片和资产记录保存在本机。每人用自己平时记账的设备作为汇总来源。

令牌默认存于浏览器会话。勾选「在这台设备上记住令牌」会将它存入当前浏览器的本地存储，适用于本人独用的设备。备份包含账本和以前手动导入的汇总。

## 照片识别账单

上传照片后点「识别账单」，核对金额、日期、商户和分类后点「确认填入」，最后保存记录。照片由浏览器内的 Tesseract.js 6.0.1 识别。引擎、核心 6.0.0 和简体中文、英文模型位于 `pwa/ocr/v6/`，构建时复制到站点，许可证随资源保留。

模型来自 `@tesseract.js-data/chi_sim@1.0.0` 和 `@tesseract.js-data/eng@1.0.0` 的 `4.0.0_best_int`。资源使用固定版本，每次识别仅加载当前设备需要的核心。

首次识别需联网下载资源。线上版的资源会缓存，浏览器保留缓存时可以离线重用。独立 HTML 从线上站点加载识别资源。识别结果需要人工核对，已有照片再次识别使用存储的压缩附件，新上传照片使用本次选择的原图。
